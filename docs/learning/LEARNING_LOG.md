# 学习日志

## 2026-09-24：Python/Windows路线替换与M0.1.1

用户将原方案改为全Python/Windows仿真。旧版工具链阻断作为历史记录保留，本版不再要求那些工具。
当前程序是一个入口、四个逻辑组件名；模块职责仍分开规划。今后数据总线/存储是接口适配实现，不改变Telemetry/Snapshot或控制安全链语义。

当前启动链：ems.py→cli.main→load_config→instance_lock→SQLite启动标记→日志/心跳→停止释放锁→再次启动保留标记。没有Tag或遥测。
为何用实例锁：防止两个进程写同一数据目录。Windows字节锁随进程死亡释放，不凭PID文件存在就判断运行。
为何不能只看status.json：崩溃可能留下旧RUNNING，必须结合锁与新鲜度。
为何SQLite要显式close：连接的with事务上下文不等于关闭连接；第一轮测试曾因测试连接未关闭导致Windows临时目录清理失败，修复后全部通过。这是实际遇到并验证的问题。

11项测试通过，Demo验证两轮启动标记一致。GUI尚未实现，捆绑Python缺Tcl init.tcl，是M02前置准备；M01没有该依赖。
下一步由用户验收M0.1.1，未经授权不写M0.1.2。
